# Объект «Гранит»

3D-игра для Android (и любого современного браузера): вы — командир сверхсекретного артиллерийского комплекса, октябрь 1944 года. Комплекс живёт сам по себе. Около 50 человек личного состава несут службу, едят, спят, сменяются на постах, чинят технику и подносят снаряды. Противник наступает и ищет объект, среди своих скрывается агент. Вы ходите по комплексу от первого лица и командуете через людей: говорите с ними лично, по телефону или с планшета управления огнём.

Готовая сборка для Android лежит в `release/objekt-granit-0.5.0.apk`.

---

## Быстрый старт

### На телефоне (Android 7.0+)
1. Скопируйте `release/objekt-granit-0.5.0.apk` на телефон и откройте его.
2. Разрешите установку из этого источника, если система спросит.
3. Запустите «Объект „Гранит“». Игра работает без интернета.

Если экран белый или игра тормозит, откройте главное меню → «Графика» и выберите уровень ниже. На слабых видеочипах и при малой памяти игра сама выбирает минимальное качество. При сбое видеочипа игра сохраняется и полностью перезапускает себя на уровень проще, с того же места: Android WebView после сбоя блокирует 3D-графику до перезапуска приложения. Если появилось сообщение «Не удалось включить 3D-графику» — нажмите «Перезапустить игру»; если не помогло — обновите «Android System WebView» и «Chrome» в Google Play.

### В браузере (для разработки)
```bash
npm install
npm run dev          # http://localhost:5173
```

## Зависимости

| Что | Версия | Зачем |
|---|---|---|
| Node.js | 20+ (проверено на 22) | сборка и тесты |
| three | 0.187 | 3D-графика (единственная зависимость игры) |
| typescript, vite, vitest | 7.0 / 8.3 / 5.1 | язык, сборщик, тесты |
| JDK | 17+ (проверено на 21) | сборка APK |
| Android SDK | platform 35, build-tools 35 | сборка APK |
| playwright (необязательно) | любая с Chromium | скриптовые прогоны в браузере |

Ни картинок, ни звуков, ни моделей извне нет. Текстуры, модели, анимации и звук генерируются кодом при запуске.

## Сборка

### Веб-версия
```bash
npm run build        # проверка типов + сборка в dist/
npm run preview      # раздача dist/ на http://localhost:4173
```

### Android APK
```bash
export ANDROID_HOME=/путь/к/android-sdk     # или sdk.dir в android/local.properties
npm run android                            # веб-сборка + APK (release)
# результат: android/app/build/outputs/apk/release/app-release.apk
```
`npm run android` сначала собирает веб-версию. Затем Gradle копирует `dist/` в `assets/www` и упаковывает APK. Оболочка — один класс `MainActivity` с полноэкранным WebView, сторонних библиотек нет. Игра грузится из APK через локальный виртуальный хост, внешние запросы заблокированы.

APK подписан ключом `android/keystore/granit-sideload.jks` (пароль `granit1944`). Ключ подходит только для самостоятельной установки и обновления поверх старой версии. Для публикации в магазине создайте свой ключ и пропишите его в `android/app/build.gradle`.

### Тесты
```bash
npm test             # vitest: планировка, баллистика, сутки жизни гарнизона,
                     # вся кампания от начала до конца, детерминированность сохранений
npm run play -- boot # прогон в настоящем браузере со снимками экрана (нужен playwright
                     # и запущенный npm run preview); сценарии: boot, tour, gameplay,
                     # phone, lowq, contextloss — снимки в scripts/out/
```

## Управление

**Телефон:** левый круг — движение (неполное отклонение — медленный шаг, до упора — бег), палец по экрану — обзор. Кнопка-подсказка внизу — заговорить или осмотреть. «Журнал», «Карта», «×1» (ускорение времени), «≡» — пауза. Кнопки «Фонарь» и «Бег». Системная кнопка «Назад» закрывает окна и ставит игру на паузу.

**Клавиатура и мышь:**

| Клавиша | Действие |
|---|---|
| W A S D / стрелки | движение |
| мышь (щелчок по экрану захватывает курсор) | обзор |
| Shift | бег |
| E | заговорить / осмотреть |
| 1–9 | пункт диалога |
| Tab или J / M | журнал / карта района |
| F | фонарь |
| T | ускорение времени ×1 / ×4 / ×12 |
| F5 / F9 | быстрое сохранение / загрузка |
| Esc | закрыть окно / пауза |

## Как играть (тестовый сценарий вертикального среза)

1. **Новая кампания → выбор командира.** Мужчина в серой шинели или женщина в длинном чёрном плаще. К вам обращаются «господин» или «госпожа оберст». Посмотрите вниз — видно своё тело. В зеркалах (помещение командира, офицерская, казарма) видно своё отражение.
2. **05:40, у шлагбаума.** Начальник штаба ждёт вас. Подойдите и нажмите «Говорить», затем «Доложите обстановку».
3. **05:45–06:10 — построение на плацу.** Гарнизон сам идёт из казарм через тоннель и строится. В 06:00 начальник штаба докладывает вам о составе.
4. **Командный центр.** Главный портал → тоннель → дверь GEFECHTSSTAND. Там карта района, планшет управления огнём, телефон и пульт тревоги. Познакомьтесь с командиром батареи, начальником охраны и офицером контрразведки.
5. **Секретный сектор.** Пост у решётки проверит документы. Осмотрите установку «Конрад» в ангаре.
6. **Глава II: первая огневая задача.** Посыльный приносит радиограмму. Откройте планшет управления огнём и выберите донесение «склад» (понтонный парк). Выберите орудие, вид огня и снаряд, затем «Открыть огонь». Расчёт сам соберётся, рассчитает установки, наведёт, зарядит и выстрелит. Через минуту наблюдатель доложит: «недолёт 200, вправо 260». Введите поправку дальности и угломера и повторите. Когда цель накрыта, переходите на серию.
7. **Патрули и караул.** Начальник караула: «Приказы» → «Усилить сектор» — сержант сам подберёт людей. Постовая ведомость в караульном помещении — новый патруль с маршрутом, временем и проверкой всех встречных.
8. **Глава III: агент.** Ночью гаснет свет. Механик проведёт диагностику, либо осмотрите генератор сами («Осмотреть на предмет вмешательства»). Найдите следы: окурок, размер сапога. Расспросите людей («Не замечали ли вы…», «Где вы были в 01:20?»). Сверьте предъявленные документы с картотекой в архиве. Поставьте подозреваемого под наблюдение, вызовите на допрос, передайте дело контрразведке. Ошибочный арест бьёт по доверию гарнизона.
9. **Сохранение.** Журнал → «Система» либо койка командира. Автосохранение — раз в сутки и при сворачивании приложения.

Дальше: глава IV (воздушная тревога, секретный пакет, ночной удар «Конрадом» по штабу противника), глава V (сутки обороны до подхода резервов) и итог кампании.

### Архитектура
- **Симуляция отделена от графики.** `src/sim` не импортирует three.js и работает в Node. На этом построены тесты: сутки жизни гарнизона, вся кампания, сохранение и загрузка.
- **Системы общаются через шину событий** (`core/events.ts`: `arty:shot`, `npc:died`, `alert:changed`, `radio:message`…) и узкие интерфейсы корня `Sim`. Общего «скрипта на всё» нет.
- **ИИ людей — выбор по полезности плюс планы.** Каждая система предлагает человеку варианты целей с оценкой: распорядок, пост, патруль, расчёт орудия, ремонт, подноска, приказ, укрытие, бой… NPC сам выбирает лучшую. Чтобы не метаться, текущая цель сохраняется, пока новая не станет заметно важнее. Цель исполняется планом из простых шагов: идти, действовать, следовать, встать на пост расчёта, вызвать функцию, ждать. Есть восприятие (дальность зависит от света, погоды и стен), память о событиях и потерях, наблюдения, из которых складываются показания.
- **Всё состояние — простые данные.** Люди, их планы, патрули, улики, агенты, орудия, противник, миссии, время, погода. Сохранение — это JSON всего мира, а детерминированный ГПСЧ сохраняется вместе с ним: после загрузки мир идёт дальше точно так же (это проверяет тест).

## Реализованные механики (по пунктам задания)

1. **Концепция.** Командир секретного комплекса, 1944 год, экспериментальная 38-см установка «Конрад» и две 21-см гаубицы.
2. **Формат.** 3D от первого лица, живой объект; командование через людей, планшеты и телефон, а не через меню-«бога».
3. **Комплекс.** Командный центр, основная и запасная огневые позиции, рельсовая позиция «Конрада» с ангаром, два склада боеприпасов, караульное помещение с оружейной, мастерская, ремонтный цех, генераторная, радиостанция, наблюдательные вышки и КП батареи. Казармы, столовая с кухней и складом продовольствия, медпункт, помещения командира и офицеров, архив, контрразведка с камерой. Склад топлива, КПП, периметр, тоннели (главный, снарядный, штабной), секретный сектор (КБ, ангар, лаборатория), автопарк, плац.
4. **Живые NPC.** У каждого: имя, фамилия, звание (артиллерийские и общевойсковые), должность, подразделение, возраст, опыт, здоровье, усталость, голод, мораль, дисциплина, отношение к командиру, распорядок, текущая задача, послужной список, приметы, память.
5. **Распорядок дня.** Подъём, построение с докладом, завтрак, обед, ужин, служба по должности, смена караула (06:00 и 18:00), личное время (курилка, столовая, офицерская), отбой. Ночная смена, усиленная ночная охрана, ночные патрули. Ночью темно и выше риск проникновения.
6. **Артиллерия.** Расчёт из командира, наводчика, заряжающего, номеров и подносчика. Приказ «Орудие №2 — подготовить огонь»: расчёт сам собирается, считает, наводит, заряжает, стреляет и докладывает.
7. **Управление огнём.** Координаты, дальность, угломер в делениях, тип снаряда (5 видов), заряды, поправки по дальности и направлению, метеосводка (может устареть). Влияют износ ствола, состояние матчасти и расчёта, время подготовки, расход боеприпасов. Виды огня: одиночный, серия, залп батареи, огневой налёт, контрбатарейная стрельба, подавление, перенос огня, «Стой! Прекратить огонь».
8. **Разведка.** Противника на карте не видно: только донесения НП, разведгрупп, перехвата, аэрофотоснимков, соседей, звукометристов и штаба. У донесений есть надёжность A–D, давность и погрешность. Бывают устаревшие, неполные и ложные. Наблюдатель докладывает, куда легли разрывы и что с целью.
9. **Противник.** Подразделения сами наступают, окапываются, маскируются, отходят под огнём и меняют маршруты. Ставят ложные позиции, ведут артиллерийский огонь, засекают батарею по звуку, ищут объект разведгруппами и самолётами, пытаются уничтожить батарею налётами и диверсионными группами. Мосты можно разрушить.
10. **Патрули.** Состав, маршрут (8 штатных), время смены, временные патрули на N часов, уровень допуска, режим «проверять всех». Патрули ходят, останавливают людей, проверяют документы, докладывают и реагируют на тревогу.
11. **Документы.** Владелец, звание, часть, должность, возраст, допуск, зоны, серия, дата и место выдачи. Проверка на постах и патрулём: в порядке — пропускает, несоответствие — задерживает и докладывает. Без подтверждённой угрозы на людей не нападают.
12. **Командир и патрули.** Патруль приветствует командира, докладывает и выполняет приказы: продолжить патрулирование, проверять всех, за мной, усилить сектор, занять пост, вернуться на маршрут.
13. **Иерархия.** Командир → старшие офицеры → командиры групп → сержанты → солдаты. «Сержант, усилить восточный сектор» — сержант сам выбирает бойцов.
14. **Шпионы.** Агент — обычный человек гарнизона с подделанными документами. Он ведёт наблюдение, роется в архиве, выходит в эфир и готовит диверсии, только когда никто не видит. Игра не говорит, кто он.
15. **Контрразведка.** Косвенные признаки (не там, где должен; сомнительные документы; ночные хождения; попытки пройти в закрытые зоны; передатчик в эфире), показания, проверка алиби. Действия: наблюдать, ограничить допуск, вызвать на допрос, поставить наружное наблюдение, задержать, передать дело. Офицер абвера высказывает своё мнение.
16. **Саботаж.** Генераторы, радиостанция, коммутатор, прицелы орудий (снаряды ложатся мимо), подъёмник установки, грузовики, поджог склада боеприпасов, порча продовольствия, слив топлива. Срабатывает с задержкой: сначала видны последствия, потом выясняется причина. На месте остаются следы.
17. **Тревога.** Зелёный, жёлтый, оранжевый, красный, плюс воздушная тревога и светомаскировка. По тревоге выставляются дополнительные посты, патрули работают круглосуточно, свободные остаются в расположении, расчёты встают к орудиям. Звучит сирена, меняется свет.
18. **Ресурсы.** Пять видов снарядов, топливо (генератор его расходует), продовольствие, медикаменты, запчасти, электричество (основной и резервный генератор), связь (радио и телефон), рабочая сила.
19. **Ремонт.** Износ, поломки, механики сами диагностируют, носят запчасти и чинят. Ремонт ускоряется помощниками и замедляется усталостью. Командир задаёт приоритет.
20. **Снабжение.** Заявка: что и сколько, вес, число машин, охрана, ночной рейс. Колонна уходит и возвращается. Её могут разбить: потери груза, машин и людей. Грузы разгружают люди.
21. **События.** Прибытие нового офицера (может быть подделкой — проверяется запросом в штаб), поломки, нехватка, подозрительный человек у ограждения, потеря связи, воздушная тревога, разведка противника, саботаж, инспекция штаба, секретный пакет, срочный огонь по заявке пехоты, травмы, ссоры между подразделениями. События выбираются по весам из обстановки, а не по одному сценарию.
22. **Отношения.** Благодарность, повышение, перевод, назначение командиром, отпуск, выговор, наряд, арест. Взыскание по делу укрепляет дисциплину, без дела — подрывает доверие всего подразделения.
23. **Секретность.** Зоны с уровнями допуска (общий, служебный, штабной, особой важности), картотека, проверка на постах, ограничение допуска отдельным людям. Чем больше противник знает об объекте, тем точнее его удары.
24. **Карта района.** Объект, НП с линиями связи, дороги, населённые пункты, мосты, леса, высоты, река, дальность орудий. Противник отмечен только по донесениям, с их давностью и погрешностью.
25. **Кампания.** 5 глав: прибытие и знакомство → первый огневой → агент на объекте → охота на «Гранит» (налёт, секретный приказ, удар «Конрадом») → последний рубеж. Несколько концовок по итогам.
26. **Визуал.** Бетон со следами опалубки и потёками, грязь, ржавчина, мешки с песком, маскировочные сети, дым, туман, дождь, мокрый снег. Ночь со звёздами, запечённый свет ламп по всему бункеру, динамические тени, фонари, прожекторы, пожары, вспышки выстрелов.
27. **Анимации.** 34 анимации: ходьба, бег, переноска, работа, ремонт, вращение маховиков наводки, досылание снаряда, сидя за столом, письмо, еда, радиосвязь, разговор, спор, сон, проверка документов, предъявление, приветствие, команда, осмотр, бинокль, курение, дремота, укрытие, стрельба, лёжа. Разные люди двигаются по-разному: у каждого своя фаза движения.
28. **Интерфейс.** На экране только время, тревога, питание, связь, люди, боеприпасы, задачи и активные приказы. Остальное открывается по необходимости — обычно через мир (стол, телефон, доска, сейф, койка).
29. **Аудио.** Синтез: далёкая канонада, выстрелы, разрывы, шаги, морзянка и эфир, телефон, генератор, вентиляция, лязг ремонта, речь, сирена, дождь, ветер, самолёты. В бункере звук глухой и гулкий, на улице открытый.
30. **Архитектура.** Отдельные системы: все перечисленные в задании, плюс CombatSystem, EnemySystem, EventDirector, RadioSystem.
31. **ИИ.** Выбор по полезности, приоритеты, планы, восприятие, события, расписание, память; у расчёта орудия — конечный автомат фаз.
32. **Потери.** Опытного специалиста заменяет менее опытный. Гибель командира группы оставляет вакансию с исполняющим обязанности — нужно назначить замену. Люди помнят погибших, падает мораль. Жестокость не изображается: раненые лежат, санитары оказывают помощь.
33. **Сохранение.** Сохраняется весь мир (перечень — в «Архитектуре»). После загрузки мир продолжается из того же состояния: детерминированность проверяется тестом.
34. **Главный принцип.** Ходить, говорить, получать доклады, проверять охрану, отдавать приказы, расследовать, снабжать, стрелять — всё через мир и людей.
35. **Вертикальный срез.** Всё из списка есть и работает вместе с полной кампанией.
36. **Рабочий проект.** Исходники, сборка, APK, тесты и этот документ.

## Известные ограничения
- Модели людей строятся кодом: гладкий торс с анатомией, лица (глаза, нос, уши, брови, рот), кисти, форма по должности (шинели, кожаный плащ, комбинезоны, фартук, повязка санитара), снаряжение (подсумки, фляга, противогаз, кобура), каски и фуражки. Детализация зависит от качества графики. Внешних моделей и текстур нет, поэтому до фотореализма далеко — это компромисс ради работы на телефонах.
- Отражения в зеркалах рисуются, только когда командир рядом.
- На слабых телефонах выбирайте качество «Низкое» или «Минимальное».
- Реальное устройство в этой среде проверить нельзя: APK собран и проверен в Chromium (тот же движок, что и в Android WebView), но не на живом телефоне.
